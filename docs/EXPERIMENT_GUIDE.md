# طرح از پیش تعیین‌شدهٔ آزمایش‌ها

این طرح پیش از مشاهدهٔ نتایج نهایی ثبت شد. فایل‌های `experiments/pilot.json` و `experiments/final.json` ورودی و بودجه را تعیین می‌کنند.

| پرسش | واحد مقایسه | مجموعهٔ منتخب |
|---|---|---|
| RQ1 سازگاری | زمان کل دستهٔ یکسان، زمان ساخت، زمان Z3، و بردار پاسخ | همهٔ ورودی‌های اصلی. چهار کوئری برای مصنوعی UNSAT شامل کل، حذف دو عضو تزریقی در دو کوئری جدا و حذف یک قید پس‌زمینه. برای SAT و دادهٔ عمومی یا دستی یک کوئری کل. |
| RQ2 استخراج | زمان یک MIS یا تشخیص SAT، تعداد فراخوانی و اندازهٔ خروجی و core | همان ورودی‌ها، چهار روش. مقایسهٔ زمان استخراج روی UNSAT، مقایسهٔ paired-good برای سرعت. |
| RQ3 صحت | کل و حذف هر عضو، بازیابی دقیق تزریق و ممیزی مستقل | همهٔ MISهای گزارش‌شده، به‌علاوه بررسی پس‌زمینه و هستهٔ تزریقی. |
| RQ4 افق | نتیجه و زمان در (N = 2,3,4,5,10,20,50) | همیشه SAT، همیشه UNSAT، رخداد دیرهنگام، و تأخیر مثبت در مرز افق. |
| RQ5 مقیاس | روش و وضعیت موفقیت یا مهلت در هر اندازه | خانوادهٔ Mixed ثابت با MIS سه‌عضوی در (12,30,60,120,240,500,1000,2000,5000). |

خانوادهٔ varied با سه Seed و اندازهٔ تزریق ۲، ۳ و ۴ در اندازه‌های ۳۰ و ۶۰، یک تضاد simple چهارتایی در ۳۰، و دو ورودی SAT، پوشش مکمل می‌دهند. ده ورودی دستی نفر دوم و دو زیرمجموعهٔ عمومی با معیار قابلیت نمایش اضافه شده‌اند. تغییر اندازهٔ یک خانواده و اجرای همان ورودی در ده نوبت، نمونه‌های مستقل از یک جامعهٔ صنعتی ایجاد نمی‌کند.

روش‌ها به‌صورت چرخشی و متوالی روی یک ماشین اجرا می‌شوند. بودجهٔ هر کوئری ۷۰۰ میلی‌ثانیه، بودجهٔ کل پردازش جداگانه سه ثانیه، و سقف فضای آدرس هر پردازش لینوکس ۷۶۸ MiB است. پایلوت دو تکرار دارد و اجرای نهایی ده تکرار. مقدار Seed حل‌کننده ۱۷ است. ساعت `perf_counter` زمان رمزگذاری، ساخت حل‌کننده و کوئری‌ها را در زمان کل ثبت می‌کند. بارگذاری JSON و شروع فرایند فقط در زمان worker منظور می‌شوند. اعتبارسنجی MIS جدا زمان‌سنجی می‌شود و در بودجهٔ کل فرایند می‌گنجد. بازه‌های اطمینان و آزمون‌ها بر پایهٔ موارد مدل‌سازی‌شدهٔ متمایز گزارش می‌شوند و ماهیت توصیفی دارند.

```bash
python run.py study --config experiments/pilot.json --output results/reproduced-pilot
python run.py study --config experiments/final.json --output results/reproduced-final
python analysis/analyze_results.py --study results/reproduced-final
```

همان فرمان با همان خروجی، تنظیمات، ورودی‌ها و محیط ادامه می‌دهد. یک پردازش برای هر پوشهٔ مقصد اجرا کنید. رکوردهای JSON اتمی دادهٔ خام اصلی هنگام قطع سخت‌اند. اجرای مجدد CSV را از رکوردها می‌سازد. برای اجرای مستقل به مقصدی تازه بنویسید. فرمان قدیمی `benchmark` طرح پایلوت پیشین و سه روش تاریخی را حفظ می‌کند.
