# تغییرات نسبت به مبنای پروژه

- فضای نام سیگنال و فعال‌ساز جدا شد و خطاهای ورودی و UNKNOWN در CLI گزارش می‌شوند.
- QuickXplain، نوع SAT مولد و تنوع محدود پارامترهای Mixed اضافه شد. مسیر پایلوت قدیمی همان طرح و سه روش اصلی را اجرا می‌کند.
- مطالعهٔ قابل ادامه با بودجهٔ فرایندی، seed حل‌کننده، هش ورودی‌ها و دو سطح اعتبارسنجی افزوده شد.
- دادهٔ عمومی گزینش‌شده، فهرست داده‌ها، تحلیل جفت‌شده و شواهد واقعی RQ1–RQ5 اضافه شدند.
- اسکریپت نصب، CLI بازتولید، نوت‌بوک، آزمون خودکار و مدارک فارسی همراه نسخه هستند.
