# تقسیم وظایف تیم سه‌نفره

| نفر | مسئول اصلی | خروجی مورد انتظار |
|---|---|---|
| ۱ — Developer | کدهای `src/team3fm`، رفع اشکال، تست‌ها و نحوه اجرا | کد مرتب و تست‌شده + README |
| ۲ — Data & Experimenter | گسترش ورودی‌های `benchmarks/`، تنظیم `experiments/config.json`، اجرای منصفانه آزمایش‌ها | داده‌های JSON و CSV خام، تنظیمات و خطاها |
| ۳ — Analyst & Presenter | بررسی مستقل MISها، تحلیل CSV، نمودار، گزارش و پاورپوینت | تحلیل RQ1 تا RQ5 و ارائه فارسی |

هر سه نفر باید قادر به اجرای `python run.py demo` و توضیح تفاوت `SAT/UNSAT/MIS` باشند.

## GitHub برای کار گروهی

1. یک ریپوی عمومی GitHub بسازید و پروژه را در شاخه `main` قرار دهید.
2. برای نفر دوم و سوم از بخش تنظیمات ریپو دعوت **Collaborator** بفرستید (مخزن عمومی به‌تنهایی مجوز ویرایش نمی‌دهد).
3. هر نفر قبل از تغییرات `git pull` بزند و ترجیحاً روی شاخه مختص خودش کار کند (`data/benchmarks` یا `analysis/charts`).
4. تغییرات در قالب Pull Request بررسی و ادغام شوند. هیچ‌کس `results/pilot/` را بازنویسی نکند.
5. قبل از ادغام کد، تست‌ها را اجرا کنید. در گزارش، فقط از CSVهای خام واقعی عدد استخراج کنید.

## کارهای هنوز انجام‌نشده

این بسته یک **MVP تمیز و قابل توسعه** است؛ به‌خودی‌خود به معنای اتمام پروژه استاد نیست. همچنان ارزیابی کامل، بنچمارک متنوع، تعیین جایگاه QuickXplain/MARCO و FRET/Hanfor و آزمایش روی داده‌های بزرگ‌تر باقی‌اند. هر مورد را پس از بررسی نیاز واقعی و هماهنگی استاد انجام دهید.
