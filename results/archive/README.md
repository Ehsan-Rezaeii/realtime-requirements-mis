# بایگانی

بستهٔ اصلی نفر دوم و یادداشت‌های داخلی در کامیت محلی ممیزی‌شدهٔ `c3de51a` نگهداری می‌شوند. ورودی‌های دستی مورد استفاده در مطالعه در `benchmarks/manual/` و داده‌های خام مطالعهٔ نهایی در `results/final/raw/` موجودند.

اجراهای Windows اولیه عمدتاً سه تکرار دارند و commit آن‌ها نامعلوم است. ابزار Windows در یادداشت خود نسخهٔ Z3 را 5.4.1 گزارش کرده و این ادعا از اجراهای لینوکس کنونی قابل وارسی نیست. دو تصویر پایلوت پیوست گفتگو بودند. اعداد نمودارهای تحویل از CSV جدید استخراج شده‌اند. شناسه‌های نمودارهای قدیمی برای تطبیق قطعی با یک اجرای جدید در دسترس نبودند.
