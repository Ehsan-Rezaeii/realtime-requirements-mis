# تحلیل

`python analysis/analyze_results.py --study results/final` جدول‌های CSV و نمودارهای PNG/SVG را از `raw/` و `environment.json` تولید می‌کند. هر روش با شناسهٔ مورد و تکرار جفت می‌شود. برای مقایسهٔ زمانی، هر دو عضو جفت باید موفق باشند. نمودارهای میانه فقط زمان اجرای موفق را نشان می‌دهند و شمار شکست در جدول‌ها و نمودار مقیاس مشخص است.

`paired_inference.csv` آزمون Wilcoxon دوطرفه، اصلاح Holm، A12 و فاصلهٔ bootstrap با ۱۰٬۰۰۰ بازنمونه برای نسبت زمان را روی میانهٔ موارد مصنوعی ۳۰ قیدی محاسبه می‌کند. این نمونه‌ها خانواده‌های طراحی‌شده‌اند. ده تکرار هر مورد به یک میانه تبدیل می‌شوند. A12 احتمال برتری روش در مقایسهٔ تمام زوج‌های میانهٔ زمان است، که به تساوی وزن نیم می‌دهد. بازهٔ bootstrap از بازنمونه‌گیری موردها به دست می‌آید. آزمون Mann–Whitney برای این مقایسهٔ جفت‌شده به کار نمی‌رود.

اسکریپت `plot_results.py` برای قالب CSV پایلوت قدیمی باقی مانده است.
